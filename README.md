# POGIOS
YOUR COMPUTER. YOUR POGIOS.

POGIOS est un projet de système d'exploitation indépendant, développé avec l'ambition de posséder son propre noyau, son environnement graphique et son écosystème d'applications.

⚠️ AVERTISSEMENT — SYSTÈME EN DÉVELOPPEMENT

POGIOS est actuellement en cours de développement.

Il est fortement recommandé de tester POGIOS dans une machine virtuelle, comme :

Oracle VirtualBox.

VMware.

QEMU.

L'installation sur un véritable ordinateur n'est pas recommandée pour le moment.

En effet, le système ne dispose pas encore de tous les pilotes, mécanismes de sécurité et fonctionnalités nécessaires pour garantir un fonctionnement fiable sur du matériel physique.

Une installation sur un véritable PC pourrait entraîner des dysfonctionnements, une perte de données ou rendre l'ordinateur inutilisable.

Utilisez une machine virtuelle et évitez de l'installer sur votre ordinateur principal.

La compatibilité avec les vrais ordinateurs sera étudiée lorsque le développement aura suffisamment avancé.
